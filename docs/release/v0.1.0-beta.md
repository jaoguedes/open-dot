# Open Dot v0.1.0-beta — rascunho das notas

> **Rascunho.** Não publicado. A tag e o release só são criados pelo mantenedor com `scripts/release/publish.sh --execute`.

Primeira versão pública. Beta: só o que foi validado está ligado.

## Destaques

- Revisão do Gmail em modo somente leitura, feed privado com fontes, monitor de sites, leitura de GitHub e Vercel.
- Aprovação do conteúdo exato antes de qualquer escrita; envio de e-mail continua desligado.
- Runner desktop com Codex: proposta, aprovação e aplicação num worktree isolado; commit local só com confirmação nativa separada.
- Memória de projeto cifrada com consentimento e retenção.

## Segurança nesta versão

- O início do login não revela mais o e-mail do dono.
- Limite de taxa por origem no pareamento do Runner e no início do login (migração `0017`).
- Modo só `OWNER_EMAIL` fixa a primeira identidade Google; `OWNER_GOOGLE_SUB` recomendado.
- Configuração versionada só com placeholders; HSTS; CI com actions fixadas por SHA e sem execução de código de fork nos runners nativos.
- Varredura de segredos e dados pessoais na CI e em hook opcional.

## Licenças

Código AGPL-3.0-only ou licença comercial; Dot com licença só de visualização; quem redistribui ou faz fork troca o Dot pelo Marcador.

## Limitações conhecidas

- Instaladores não assinados; Runner validado só no macOS Intel; executor desligado no Windows.
- Claude Code experimental e desligado; Cursor indisponível.
- Sem shell/testes de projeto, paralelismo, merge ou push automáticos.

## Atualização de quem já tem instância

Aplique a migração `0017` antes do Worker novo (`npm run deploy` faz na ordem) e crie `.deploy.local.json` com a origem da sua instância.
